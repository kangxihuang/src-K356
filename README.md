# (附文档)Python+深度学习+TensorFlow 基于文本挖掘的酒店评论数据情感分析平台

**技术栈**：Python、Django、TensorFlow、深度学习、Vue3、MySQL

### 系统简介

本系统是基于 Python + Django + TensorFlow 构建的酒店评论情感分析平台，采用前后端分离架构，前端使用 Vue3 + Element Plus + ECharts，后端使用 Django REST Framework 提供接口，通过 LSTM 深度学习模型对酒店评论文本进行情感倾向自动识别。系统包含普通用户端与管理员端两类角色，覆盖酒店浏览、评论发布、情感自动分析、数据可视化以及后台运营管理完整链路。
 
### 核心功能
 
### 普通用户端

 
- 用户注册：填写用户名、密码、昵称完成注册，用户名至少 3 字符、密码至少 6 字符，注册后自动生成默认头像并返回登录令牌。 
- 用户登录：使用用户名与密码登录，校验账号状态，登录成功后返回 token 与用户信息用于后续鉴权。 
- 查看与修改个人信息：获取当前登录用户资料，可修改昵称、邮箱、手机号、头像，并支持修改登录密码。 
- 酒店列表浏览：分页查看酒店列表，支持按城市、星级、酒店名称关键字筛选，默认按平均评分倒序排列。 
- 酒店详情查看：查看酒店封面、图片集、省份、城市、地址、电话、星级、简介、设施服务、平均评分与评论数量。 
- 城市筛选：获取系统中全部酒店所在城市去重列表，用于前台城市筛选下拉。 
- 发布评论：登录后对指定酒店发布评论，填写评分与评论内容，内容至少 5 个字，发布时自动记录评论 IP。 
- 评论情感自动分析：发布评论时自动调用 LSTM 模型预测情感倾向与置信度，模型未加载时回退到关键词规则判断。 
- 酒店评分联动更新：评论发布后自动重新聚合该酒店平均评分与评论总数并回写酒店记录。 
- 我的评论：查看当前登录用户自己发布的全部评论列表，按发布时间倒序。 
- 评论列表浏览：无需登录即可分页浏览已发布评论，支持按酒店、情感标签筛选。 
- 前台数据可视化：查看评论总数、酒店数量、注册用户数、情感分布，以及按日期的情感趋势、词云、酒店对比、用户-酒店关联关系图。
 
### 管理员端

 
- 数据仪表盘：查看评论总数、酒店数量、注册用户数、正面评论数统计卡片，并以饼图展示情感分布、柱状图展示酒店评论排行。 
- 用户管理：分页查看用户列表，支持按用户名/昵称关键字与角色筛选，可编辑昵称、邮箱、手机、角色、状态与重置密码。 
- 用户删除：删除指定普通用户，管理员账号受保护不可删除。 
- 酒店管理：分页查看酒店列表，支持按名称关键字搜索，展示封面、城市、星级、评分、评论数等字段。 
- 新增酒店：填写名称、封面、省份、城市、地址、电话、星级、简介创建酒店，图片集与设施服务以 JSON 存储。 
- 编辑酒店：修改酒店名称、封面、省份、城市、地址、电话、星级、简介、图片集与设施服务。 
- 删除酒店：删除指定酒店记录。 
- 评论管理：分页查看全部评论，支持按评论内容关键字、情感标签、审核状态筛选。 
- 评论审核：对待审核评论执行通过、对已发布评论执行下架、对已删除评论执行上架操作。 
- 评论删除：删除指定评论，并自动重算所属酒店的平均评分与评论总数。 
- 模型状态查看：查看情感模型列表，包含模型名称、版本、准确率、训练样本数、状态、训练日志与创建时间。 
- 训练数据统计：查看已标注评论数、正面评论数、负面评论数、覆盖酒店数，以及各酒店正负样本分布条形图。 
- 触发模型训练：基于系统数据库已标注评论异步启动 LSTM 训练，数据不足 100 条时给出提示。 
- 训练进度查询：读取训练进度文件，返回当前训练步骤、百分比、轮次与准确率。 
- 文件上传：上传酒店封面等图片，校验扩展名与 10MB 大小限制，生成唯一文件名并返回访问地址。
 
### 技术栈

 后端框架Python + Django + Django REST Framework 深度学习TensorFlow / Keras（LSTM 情感分类模型） 文本处理jieba 分词、停用词过滤、词表构建与序列编码 ORMDjango ORM（聚合、分组、TruncDate 时间分组） 权限控制自定义 Token 鉴权装饰器（login_required / admin_required） 前端框架Vue3 + Element Plus 状态管理Pinia（userStore 管理登录态与用户信息） 路由Vue Router（路由守卫控制登录与管理员权限） 图表可视化ECharts（饼图、柱状图、词云、关系图） 数据库MySQL
